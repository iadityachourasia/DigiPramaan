Use `PoweredBy` in the footer bottom strip or on an embedded widget.

```jsx
<PoweredBy logo={<img src="/assets/logo/ux4g-logo-mark-blue-clean.svg" alt="UX4G" height="14" />} href="https://ux4g.gov.in" />
```

- Pass the real mark from `assets/logo/`; the type fallback exists so nothing is ever redrawn.
