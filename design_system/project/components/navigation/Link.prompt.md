Use `Link` for navigation inside text; use `Button` for actions.

```jsx
<Link href="/guidance/4-2">Guidance note 4.2</Link>
<Link href="https://ux4g.gov.in" external>UX4G</Link>
```

- Keep the underline. Colour alone is not enough to mark a link.
- `external` adds the glyph, `target="_blank"`, `rel`, and screen-reader text.
